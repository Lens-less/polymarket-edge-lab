# Code of conduct

## Our standard

We welcome respectful, evidence-based participation. Contributors should be
clear about uncertainty, distinguish research results from financial claims,
accept good-faith correction, and protect other people's private information.

Harassment, threats, discriminatory language, deliberate disclosure of private
information, market manipulation, credential sharing, and attempts to bypass
the repository's safety boundaries are not acceptable.

## Scope

This code applies to repository issues, pull requests, reviews, discussions,
and other spaces where someone represents this project.

## Enforcement

Maintainers may edit or remove inappropriate content and may temporarily or
permanently restrict participation. Decisions should be proportional,
documented when practical, and focused on keeping the project safe and useful.

To report conduct privately, request a private contact channel through the
maintainer's GitHub profile. Do not disclose personal data, credentials, or
security-sensitive details in a public issue. Security vulnerabilities should
follow [`SECURITY.md`](SECURITY.md).
