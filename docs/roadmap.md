## 当前版本：v1.0

### 已实现功能

- **核心做市**
  - 双侧报价挂单
  - 根据波动率自适应价差
  - 库存偏斜管理

- **风险管理**
  - 仓位限制
  - 每日亏损限制
  - 熔断机制
  - 凯利公式仓位管理

- **Alpha 信号**
  - 套利检测
  - 订单流分析
  - 竞争者检测
  - 市场状态检测

- **数据与基础设施**
  - WebSocket + REST 备用
  - 实时订单簿
  - 交易日志

- **监控**
  - 终端 UI 仪表盘
  - 延迟监控

- **安全**
  - 断连自动取消
  - 僵尸订单清理
  - 余额监控

## 已知限制

1. **单币种聚焦** - 目前一次只交易一个市场
2. **无对冲** - 无自动对冲仓位
3. **基础回测** - 历史回放功能有限
4. **无云部署** - 无 Docker 或 Kubernetes 配置
