# 常见问题解答

关于 Polymarket 做市商机器人的常见问题。

---

## 通用问题

### 这个机器人做什么？

机器人在 Polymarket 预测市场提供流动性，同时挂出买入和卖出订单。它通过买卖价差（Spread）赚取收益，并可能获得流动性奖励。

### 这合法吗？

是的，在预测市场做市是合法的。本软件仅供教育和研究目的。

### 我能赚多少钱？

无法保证。收益取决于：
- 市场状况
- 配置设置
- 仓位大小
- 市场波动率

过去表现不代表未来结果。

## 入门

### 我需要什么才能开始？

1. Python 3.11+
2. 可上网的电脑
3. 实盘交易需要：Polymarket 账户 + API 凭证

### 安装需要多长时间？

初次安装约需 10-15 分钟。建议在实盘前用 DRY_RUN 模式测试 1-2 周。

### 可以在服务器上运行吗？

可以。机器人在任何装有 Python 3.11+ 的电脑上都能运行。许多用户在云服务器（AWS、DigitalOcean 等）上运行。

### 机器人需要 24/7 运行吗？

理想情况下是，但并非必需。机器人：
- 每几秒检查市场
- 可以安全地停止和启动
- 关闭时会取消订单

## 配置

### 我应该从什么设置开始？

参见[配置指南](user/configuration.md)。从小型账户设置和保守值开始。

### MM_SIZE 和 RISK_MAX_POSITION 有什么区别？

- `MM_SIZE` - 每次新订单的数量
- `RISK_MAX_POSITION` - 单向最大总仓位

示例：如果 MM_SIZE=10，RISK_MAX_POSITION=50，达到限值前最多可以挂 5 个订单。

### 如何判断我的设置是否合适？

在 DRY_RUN 模式测试至少 1 周。监控：
- 盈亏（应为正）
- 成交率（应合理）
- 仓位（不应频繁触及限值）

## 交易

### 为什么我的订单没有成交？

可能原因：
1. 价差太大 - 其他做市商价格更好
2. 市场竞争激烈 - 考虑其他市场
3. 数量太小 - 增加 MM_SIZE
4. 价格在极端值 - 接近 0 或 1 的订单成交较少

### 为什么机器人只在一侧挂单？

当您在该方向有较大仓位时，机器人会跳过该侧挂单。这是故意的——防止过度暴露。

### 我应该交易哪些市场？

寻找：
- 高交易量（每日 $10,000+）
- 适度价差（3-10 美分）
- 距离结算至少 12 小时

避免：
- 极紧价差（过度竞争）
- 极宽松价差（无流动性）
- 即将结算的市场

### 如何切换 DRY_RUN 和 LIVE？

编辑 `.env` 文件：
```bash
DRY_RUN=true   # 模拟交易
DRY_RUN=false  # 实盘交易
```

然后重启机器人。

## 故障排查

### "Connection refused" 错误

- 检查网络连接
- 验证 Polymarket API 是否正常
- 稍后重试

### "Insufficient balance" 余额不足错误

- 检查您的 USDC/ETH 余额
- DRY_RUN 模式：重置模拟器
- 实盘模式：向交易钱包充值

### 机器人无法挂单

检查：
1. 市场数据连接是否正常？
2. 有活跃市场吗？
3. DRY_RUN 设置正确吗？
4. 查看日志中的错误

### DRY_RUN 模式亏损高

可能出现这种情况。选项：
- 等待市场回转
- 取消订单，尝试其他市场
- 调整价差设置

### 实盘亏损高

1. 立即停止机器人
2. 取消所有订单
3. 审查日志
4. 检查熔断是否触发

## 安全

### 输入 API 密钥安全吗？

安全，但请：
- 使用专用交易钱包
- 切勿分享您的私钥
- 保护好您的 .env 文件
- 切勿将 .env 提交到 git

### 如果有人获取了我的 API 密钥怎么办？

1. 立即在 Polymarket 撤销密钥
2. 从交易钱包转出资金
3. 审查最近交易
4. 如需要创建新密钥

## 高级

### 可以运行多个实例吗？

可以，但请：
- 使用不同账户
- 设置不同仓位限制
- 使用不同市场避免竞争

### 可以添加自己的策略吗？

可以。代码在 `src/strategy/` 中。谨慎修改并充分测试。

### 什么是凯利公式（Kelly Criterion）？

计算最优投注规模的数学公式。较高的 KELLY_FRACTION = 较大仓位但更多风险。我们建议大多数用户使用 0.15-0.25。
