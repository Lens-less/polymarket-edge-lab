# 安全边界

当前仓库没有已验证盈利策略，也没有受支持的新订单路径。它默认面向公开数据研究。

| 操作 | 网络 | 本地写入 | 凭证 | 新订单 |
|---|---:|---:|---:|---:|
| `run_edge_lab.py --help` | 否 | 否 | 否 | 否 |
| `run_edge_capture.py ... --validate-only` | 否 | 否 | 否 | 否 |
| `run_backtest.py --mock` | 否 | 否 | 否 | 否 |
| `run_edge_lab.py audit` | 公开网络 | 否 | 否 | 否 |
| recorder/实验命令 | 公开网络 | 是 | 否 | 否 |
| 保留的认证读取/撤单模块 | 可能 | 可能 | 是 | 否 |

`DRY_RUN=false` 不是实盘授权，也无法绕过 `assert_new_orders_disabled()`。

## 凭证

- 公开研究不要创建 `.env`，不要配置钱包或 API 密钥。
- 调试认证读取时只使用隔离钱包和可撤销的最小权限凭证。
- `.env`、日志、采集输出和支持包在分享前都要做脱敏。
- 一旦凭证误提交，立即撤销或轮换；仅从最新提交删除字符串并不能清除 Git 历史。

## 网络与地域限制

- 只访问命令文档列出的公开端点。
- 不把认证信息放在 URL、查询参数或代理地址中。
- 不使用代理规避 geoblock、平台条款或法律限制。
- 网络审计失败时保持 fail-closed；不要把未知状态解释为获准交易。

## 本地数据

采集器会写入 `data/`，数据量可能很大。保持输出目录在受控磁盘内，定期检查容量，并且不要发布 `.partial` 文件。固定 manifest、哈希和发布边界见 [`DATASETS.md`](../../DATASETS.md)。

安全漏洞请按 [`SECURITY.md`](../../SECURITY.md) 私下报告，不要在公开 Issue 中附上可利用细节或真实凭证。
