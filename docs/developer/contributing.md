# 贡献指南

感谢您有兴趣为本项目做出贡献！

## 贡献方式

- 报告错误
- 建议功能
- 改进文档
- 提交拉取请求

## 拉取请求流程

1. Fork 仓库
2. 创建功能分支：`git checkout -b feature/我的功能`
3. 进行修改并添加测试
4. 确保所有测试通过
5. 提交清晰的提交信息
6. 推送到您的 Fork
7. 提交拉取请求

## 代码标准

- 使用类型提示
- 为新功能编写测试
- 遵循现有代码风格
- 更新文档

## 测试

```bash
# 运行所有测试
pytest tests/ -v

# 运行特定测试
pytest tests/test_specific.py::test_name -v
```

## 获取帮助

- 在 GitHub 上开 Issue 报告错误或请求功能
- 创建新 Issue 前先搜索现有 Issue
